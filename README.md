# ggwave

[![crates.io](https://img.shields.io/crates/v/ggwave.svg)](https://crates.io/crates/ggwave)
[![docs.rs](https://docs.rs/ggwave/badge.svg)](https://docs.rs/ggwave)
[![CI](https://github.com/katzenpost/ggwave-rs/actions/workflows/ci.yml/badge.svg)](https://github.com/katzenpost/ggwave-rs/actions/workflows/ci.yml)

A port of [ggwave](https://github.com/ggerganov/ggwave), Georgi Gerganov's
data-over-sound modem, to safe Rust (`#![forbid(unsafe_code)]`, no
dependencies, no FFI). It carries short payloads over audio with
multi-frequency FSK, Reed-Solomon error correction and start/end markers.
It is written for Rust developers who need to exchange a few bytes with C
ggwave or with another device over a speaker and microphone.

The library turns bytes into samples and samples back into bytes; it does
no audio I/O, so you bring your own (cpal, a WAV writer, a device driver).
Payloads are at most 140 bytes, or 64 in fixed-length mode, and are neither
encrypted nor authenticated; for more data or a secure channel, use another
transport or put a protocol on top.

This crate was ported from C ggwave with the help of a large language model,
and is checked against C ggwave with interop tests.

## Install

```sh
cargo add ggwave
```

## Examples

Send a 32-byte code with Audible Fast, the protocol a phone and a T-Deck use
to swap vouchers in [hushphone](https://github.com/katzenpost/hushphone):

```rust
use ggwave::{Encoder, Parameters, Protocol};

fn main() -> Result<(), ggwave::Error> {
    // The speaker's rate; 48 kHz is also ggwave's operating rate.
    let params = Parameters { sample_rate_out: 48000.0, ..Parameters::default() };
    let code = [0x5au8; 32];

    // About 2.7 s of mono f32 samples in -1..1, at volume 25 of 100.
    let samples: Vec<f32> = Encoder::new(params)?.encode(&code, Protocol::AudibleFast, 25)?;

    // Hand `samples` to your audio output (cpal, a WAV writer, ...).
    assert_eq!(samples.len(), 131072);
    Ok(())
}
```

Listen for it: feed the microphone's samples to a `Decoder` as they arrive,
in blocks of any size, until it hands back a payload:

```rust
use ggwave::{Decoder, Encoder, Parameters, Protocol};

fn main() -> Result<(), ggwave::Error> {
    // The microphone's rate; the decoder resamples to 48 kHz itself.
    let fs = 44100;
    let params = Parameters { sample_rate_inp: fs as f32, sample_rate_out: fs as f32, ..Parameters::default() };
    let mut decoder = Decoder::with_protocols(params.clone(), &[Protocol::AudibleFast])?;

    // Stands in for the microphone: the tones as played at 44.1 kHz.
    let mic = Encoder::new(params)?.encode(&[0x5au8; 32], Protocol::AudibleFast, 25)?;

    // 20 ms blocks, as an audio input callback would deliver them.
    let heard = mic.chunks(fs / 50).find_map(|block| decoder.push(block));
    assert_eq!(heard.as_deref(), Some(&[0x5au8; 32][..]));
    Ok(())
}
```

## Contents

- [`src/encoder.rs`](https://github.com/katzenpost/ggwave-rs/blob/main/src/encoder.rs): `Encoder` turns a payload into samples; `to_i16` converts them.
- [`src/decoder.rs`](https://github.com/katzenpost/ggwave-rs/blob/main/src/decoder.rs): `Decoder` takes samples in blocks of any size and returns payloads.
- [`src/protocol.rs`](https://github.com/katzenpost/ggwave-rs/blob/main/src/protocol.rs): the twelve built-in protocols.
- [`src/reed_solomon.rs`](https://github.com/katzenpost/ggwave-rs/blob/main/src/reed_solomon.rs), [`src/resampler.rs`](https://github.com/katzenpost/ggwave-rs/blob/main/src/resampler.rs), [`src/fft.rs`](https://github.com/katzenpost/ggwave-rs/blob/main/src/fft.rs): internals ported from C ggwave.
- [`tests/`](https://github.com/katzenpost/ggwave-rs/tree/main/tests): API tests, recorded C vectors, and live C interop tests.
- [`tools/`](https://github.com/katzenpost/ggwave-rs/tree/main/tools): scripts that build C ggwave at the pinned commit and regenerate the vectors.

API documentation is on [docs.rs](https://docs.rs/ggwave).

## Status and compatibility

Version 0.1.0, on [crates.io](https://crates.io/crates/ggwave); the minimum
supported Rust is 1.73. The encoder and decoder follow C ggwave at commit
[`060aec7`](https://github.com/ggerganov/ggwave/tree/060aec73dd7123ccac200442f75bdc7369795ffe):
all twelve built-in protocols (audible, ultrasound, DT and MT, each normal,
fast and fastest), variable-length and fixed-length payloads, DSS, and
resampling to and from other sample rates. Encoded samples match C ggwave's
output, and the decoder returns what C ggwave's decoder returns for the same
audio.

## Tests

`cargo test` checks the port against waveforms rendered by C ggwave, kept in
`tests/vectors` and regenerated by `tools/gen-vectors.sh`. The live interop
tests encode and decode in both directions, with noise, against the C library
built from the pinned commit (this needs a C++ compiler and network access):

```sh
GGWAVE_C=$(tools/build-c-ggwave.sh) cargo test --release
```

CI runs `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, the
tests above, and `cargo test` on Rust 1.73. Issues and pull requests are
welcome on [GitHub](https://github.com/katzenpost/ggwave-rs).
